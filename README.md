# 🏦 Loan Prediction using Logistic Regression

This project predicts **loan approval status** using **Logistic Regression** and provides an interactive **Streamlit dashboard** for data visualization, preprocessing, model training, and prediction.

## 🚀 Live Demo

🌐 Live App: https://logistic-regression-loan-prediction.streamlit.app/

## 📌 Project Overview
The goal of this project is to predict whether a loan will be:

- ✅ **Approved (1)**
- ❌ **Rejected (0)**

based on applicant details such as:

- Gender
- Marital Status
- Education
- Applicant Income
- Coapplicant Income
- Loan Amount
- Credit History
- Property Area
- Self Employment Status

## 🚀 Features
- 📂 Automatic dataset loading (`train.csv`)
- 🧹 Null value handling
- 🔄 Categorical to numerical conversion
- 📊 Outlier detection & visualization
- 📈 Feature scaling
- 🔥 Correlation heatmap
- 🤖 Logistic Regression model training
- 📉 Model evaluation metrics
- 🎯 Interactive loan prediction system
- 💡 Explanation for why predictions are 0 or 1
- 🎨 Attractive Streamlit UI with colorful visualizations

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
